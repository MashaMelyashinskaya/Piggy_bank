# A/B-тестирование алгоритма рекомендаций

## Описание задачи

Отдел Data Science разработал новый алгоритм рекомендации постов в ленте.\
Нужно оценить, полезен ли новый алгоритм.

## Метрика

CTR (Click-Through Rate) = лайки / просмотры.

## Данные

Источник: локальная СУБД ClickHouse, таблица "portfolio.feed_actions_group".\
Данные в репозиторий не включены.

Поля:
- 'user_id' — идентификатор пользователя
- 'post_id' — идентификатор поста в ленте
- 'action' — действие пользователя к посту: просмотр, лайк
- 'time' — время действия
- 'group' — группа пользователя после сплитования

## Что сделано

1. Проверено качество сплитования.
2. Проведен AA-тест.
3. Проведен AB-тест несколькими методами:
   - T-test
   - Манна-Уитни
   - Пуассоновский бутстреп
   - Т-test + Манна-Уитни + сглаживание
   - T-test + Манна-Уитни + бакеты

## Результат

| Группа   | CTR    |
| ---------|--------|
| Контроль | 0.2096 |
| Тест     | 0.2003 |

Новый алгоритм **значимо ухудшил** CTR.
Рекомендация: **не раскатывать**.

## Стек

Python (pandas, numpy, scipy, seaborn), ClickHouse
