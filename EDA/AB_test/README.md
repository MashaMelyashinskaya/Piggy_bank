В этой директории находится проект по A/B тестированию.

## Формат

Проект сделан в Jupyter notebook: AB_test.ipynb

## Описание задачи

Заказчик - отдел DS, разработавший новый алгоритм рекомендации постов в ленте.\
Нужно оценить, полезен ли новый алгоритм.

## Описание файла с данными

Использован коннект к СУБД ClickHouse.

## Описание данных

Поля в таблице с данными:
- user_id — идентификатор пользователя
- post_id — идентификатор поста в ленте
- action — действие пользователя к посту: просмотр, лайк
- time — время действия
- group — группа пользователя после сплитования

## Результат

В ходе работы целевой метрикой выбран CTR.\
Проведено сплитование и АА-тест.\
Использованы различные методы тестирования и описана их разница:
- T-test
 - Манна-Уитни
 - Пуассоновский бутстреп
 - Т-test + Манна-Уитни + сглаживание
 - T-test + Манна-Уитни + бакеты

Итоговый вывод - новый алгоритм значимо ухудшил CTR. Раскатывать его не рекомендуется.
