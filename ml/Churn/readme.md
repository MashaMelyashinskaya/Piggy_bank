# Прогнозирование оттока клиентов банка

## Описание задачи

Из банка уходят клиенты. Маркетологи пришли к выводу, что **удерживать текущих клиентов дешевле, чем привлекать новых**.\
**Цель**: по историческим данным предсказать, уйдёт ли клиент в ближайшее время.

## Данные

Источник: [Kaggle — Bank Customer Churn Modeling](https://www.kaggle.com/barelydedicated/bank-customer-churn-modeling)\
Данные в репозиторий не включены. Ноутбук читает CSV с локального пути.

Поля:

| Признак            | Описание                              |
|--------------------|---------------------------------------|
| CreditScore        | Кредитный рейтинг                     |
| Geography          | Страна                                |
| Gender             | Пол                                   |
| Age                | Возраст                               |
| Tenure             | Стаж в банке (лет)                    |
| Balance            | Баланс на счёте                       |
| NumOfProducts      | Количество продуктов банка            |
| HasCrCard          | Наличие кредитной карты               |
| IsActiveMember     | Активность клиента                    |
| EstimatedSalary    | Предполагаемая зарплата               |
| **Exited**         | **Целевой признак** (1 — ушёл)        |

## Подход

- Сравнение моделей: логистическая регрессия и случайный лес
- Дисбаланс классов (~80/20) обрабатывался тремя способами:
  - взвешивание классов (`class_weight='balanced'`)
  - upsampling
  - downsampling

Лучший результат дало **взвешивание**.

## Лучшая модель

**Random Forest** с гиперпараметрами:
- `max_depth=10`
- `n_estimators=72`
- `min_samples_leaf=5`

| Выборка     | F1-score | ROC-AUC |
|-------------|----------|---------|
| Валидация   | 0.624    | 0.878   |
| Тест        | 0.629    | 0.861   |

Модель готова к использованию для прогноза оттока новых клиентов.
