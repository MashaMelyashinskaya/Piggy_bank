# Мэтчинг товаров (векторный поиск)

## Описание задачи

Есть база товаров и новые товары, которые нужно сопоставить с базой.  
Все товары уже представлены в виде векторов размерности 72.

**Цель**: для каждого товара из validation найти 5 наиболее похожих товаров из base и оценить качество по метрике **accuracy@5**.

## Данные

| Файл                  | Описание                                                                 |
|-----------------------|--------------------------------------------------------------------------|
| `base.csv`            | Векторное представление известных товаров (база)                         |
| `train.csv`           | Товары + id наиболее похожего товара из base (разметка экспертов)        |
| `validation.csv`      | Товары, для которых нужно найти кандидатов                               |
| `validation_answer.csv` | Правильные ответы                                                        |

Данные в репозиторий не включены.

## Что сделано

1. **Анализ данных**
   - Проверена корреляция координат совпадающих векторов.
   - Удалены 5 признаков с низкой корреляцией (< 0.5): 21, 25, 33, 59, 65.
   - Применён `StandardScaler`.

2. **Модель**
   - Использован **FAISS** (IndexIVFFlat + L2-расстояние).
   - Параметры: 1000 кластеров, `nprobe=20`, top-5 соседей.

3. **Результаты**

| Выборка     | Accuracy@5 |
|-------------|------------|
| Train       | 71%        |
| Validation  | 70%        |

В 70% случаев среди 5 предложенных кандидатов находится товар, который эксперты считают правильным мэтчем.

## Стек

Python, pandas, numpy, FAISS, scikit-learn, seaborn, matplotlib
